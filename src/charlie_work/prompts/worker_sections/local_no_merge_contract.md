## No-merge contract

Your deliverable ENDS at committing to your branch. This repository has no remote: there is nothing to push to and no pull request to open, so do not run `git push`, `git remote add`, or any `gh` command. You must **never** merge your branch into any other branch, check out or commit to the default branch, rewrite history, or edit any file under the issue directory — issue state and labels are owned by the orchestrator, which reads them from those files. A human reviews your branch and merges it; your job is to implement, test, and commit.
